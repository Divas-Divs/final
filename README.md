## Requirements

The final project is broken into two parts: Prototype and Production.

### Prototype (100pts)

* A pre-production document formatted into a single PDF:
    * A 1-2 paragraph project statement introducing the site/concept (50pts)
* At least two wireframes/comps of your final idea (you can use Figma or a similar app for this) (50pts)

### Production (300pts)

* Final site must include at least one relational database and one API source (40pts)
* Site must use a CSS framework like Bootstrap or Tailwind (40pts)
* The site should be built using tools and technologies covered in class (React/Rails) (40pts)
* All source code must be in a new GitHub repository that is shared among the group. All group members must commit and push to the project. (40pts)
* The final site must be hosted on a public server and accessible over the web (40pts)
* Business readiness and overall effort/quality (100pts)
